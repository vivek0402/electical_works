Design notes for review
  • Same columns as your Excel. Fresh: S.NO, FITTING CODE, BATCH CODE, PKDT, DRIVER CODE, PCB CODE, QUANTITY. Defective: the same, without PKDT.
  • One code per row, placed by item type. Drivers go in DRIVER CODE and PCBs/LED modules in PCB CODE. Fittings and other items (LENS, BULCK HEAD, ISENSE controller and switch) go in FITTING CODE. Please confirm the "others in FITTING CODE" rule.
  • On phones the five sparse code columns collapse into one CODE column with type (and location) underneath, beside QUANTITY; the export always uses the full Excel layout.
  • "All locations" adds a LOCATION column, with one row per item per location. Pick one location to see exactly that store's sheet.
  • Batch code and PKD are blank today, as in the sheets. They fill in once receipts and defectives start capturing them.
  • Quantity shows red when it is at or below the item's reorder level (Fresh List only).
  • Export downloads exactly the rows on screen (with the current filters) in the Excel layout shown in the preview.
